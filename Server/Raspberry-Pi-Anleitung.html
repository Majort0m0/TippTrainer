TippTrainer auf dem Raspberry Pi

Ein kleiner, stromsparender Server für das Schulnetz: Alle Geräte einer Klasse (z. B. iPads) arbeiten mit demselben Datenstand. Der Pi läuft im Hintergrund, startet beim Einschalten von selbst und braucht weder Bildschirm noch Tastatur.

Was Sie brauchen
  • einen Raspberry Pi (empfohlen: Pi 4 oder Pi 5; getestet auf Pi 5) mit Netzteil
  • eine microSD-Karte (mind. 16 GB, am besten Klasse A2) – für Dauerbetrieb noch besser eine SSD
  • möglichst ein Netzwerkkabel zum Router/Switch (WLAN geht auch)
  • einen Rechner (Windows, Mac oder Linux) zum Einrichten

Eine Internetverbindung braucht der Pi nur für die Einrichtung (Betriebssystem und Programm laden). Im Betrieb genügt das Schulnetz – nur die Übungsbilder (ARASAAC/Wikimedia) kommen aus dem Internet.

1Betriebssystem auf die SD-Karte schreiben

  1. Auf dem Rechner den kostenlosen Raspberry Pi Imager von raspberrypi.com/software installieren und starten.
  2. Gerät: Ihr Raspberry-Pi-Modell wählen.
  3. Betriebssystem: Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit). („Lite“ hat keine Bildschirmoberfläche und ist genau richtig.)
  4. Speicher: die SD-Karte wählen.
  5. Auf „Weiter“ klicken und die Einstellungen bearbeiten (je nach Imager-Version heißt dieser Schritt „Einstellungen“ oder „Anpassung“). Hier ist alles wichtig, weil der Pi später ohne Bildschirm läuft:
    • Hostname: z. B. tipptrainer (der Pi ist dann im Netz unter tipptrainer.local erreichbar – merken Sie sich den Namen)
    • Benutzername und Passwort festlegen (notieren!)
    • WLAN eintragen (nur, wenn kein Kabel benutzt wird) und das Land einstellen
    • Reiter Dienste: SSH aktivieren (Passwort-Anmeldung)
  6. Speichern, „Ja“ zum Schreiben – das dauert einige Minuten. Die SD-Karte in den Pi stecken, Netzwerkkabel anschließen und den Pi einschalten.
Nach etwa ein bis zwei Minuten ist der Pi bereit. Beim ersten Start richtet er sich selbst ein und startet eventuell einmal neu.

2Am Pi anmelden

Auf dem Rechner ein Terminal öffnen (Mac: Terminal; Windows 10/11: PowerShell) und anmelden – mit Ihrem Benutzernamen und dem Hostnamen aus Schritt 1:

ssh BENUTZER@tipptrainer.local
  • Beim ersten Mal fragt das Terminal, ob dem Gerät vertraut wird: yes eintippen.
  • Dann das Passwort eingeben. Beim Tippen erscheinen keine Zeichen – das ist normal.
  • Klappt der Name nicht, die IP-Adresse des Pi in der Geräteliste des Routers (Fritz!Box: Heimnetz → Netzwerk) nachsehen und ssh BENUTZER@192.168.x.x verwenden.

3TippTrainer-Server installieren

Im Terminal auf dem Pi diese drei Befehle nacheinander eingeben (der erste lädt das Paket von GitHub):

curl -L -O https://github.com/Majort0m0/TippTrainer/releases/latest/download/TippTrainer-Server-RaspberryPi-64bit.tar.gz
tar -xzf TippTrainer-Server-RaspberryPi-64bit.tar.gz
cd TippTrainer-Server && sudo sh installieren.sh
  • Hat der Pi kein Internet? Dann das Paket TippTrainer-Server-RaspberryPi-64bit.tar.gz auf dem Rechner herunterladen und mit scp TippTrainer-Server-RaspberryPi-64bit.tar.gz BENUTZER@tipptrainer.local: auf den Pi kopieren; danach die Befehle 2 und 3 ausführen.
  • Läuft ein Pi mit 32-Bit-System (uname -m zeigt armv7l)? Dann stattdessen das Paket …RaspberryPi-32bit.tar.gz nehmen.

Das Skript richtet alles ein: einen eigenen Benutzer für das Programm, den Dienst tipptrainer (startet bei jedem Einschalten automatisch) und legt die Daten unter /opt/tipptrainer ab. Am Ende zeigt es die Verbindungsdaten an:

  • Adresse (z. B. http://192.168.188.86:8080) und den Link mit Gerätename (http://tipptrainer.local:8080/#tt-server=…)
  • den Schlüssel (verbindet die Geräte mit dem Server)
  • das Admin-Passwort der App (zunächst lernsachen)
  • einen QR-Code im Terminal
Wichtig: Das Standard-Passwort lernsachen steht öffentlich im Quellcode. Bitte ändern Sie es (siehe Abschnitt „Laufende Nutzung“) – oder lassen Sie es bewusst, wenn ein niedriges Sicherheitsniveau für Ihre Klasse genügt.

4Geräte verbinden

iPad / Tablet (einmal pro Gerät)

  1. Das Gerät muss im selben Netz (WLAN) wie der Pi sein.
  2. In Safari den Link mit Gerätename öffnen, z. B.
    http://tipptrainer.local:8080/#tt-server=SCHLÜSSEL
    Den Link bekommen Sie am einfachsten per AirDrop, E-Mail oder Messenger auf das Gerät – oder Sie scannen den QR-Code aus dem Terminal mit der Kamera.
  3. Die App öffnet sich und ist automatisch mit dem Server verbunden. Die Datenspeicherung läuft jetzt über den Pi.
  4. Praktisch: in Safari auf Teilen → Zum Home-Bildschirm tippen. Dann startet die App wie ein normales Symbol.
Tipp: Richten Sie die Geräte mit dem Namens-Link (….local) ein. Dann bleiben sie auch verbunden, wenn der Pi in ein anderes Netz kommt und eine neue IP-Adresse bekommt.

Lehrer-PC

  1. http://tipptrainer.local:8080 im Browser öffnen (so lädt die App vom Pi, das ist wichtig – bitte nicht von einer https-Seite oder einer gespeicherten Datei öffnen).
  2. Oben auf das Speicher-Symbol → Eigener Server → Server-Adresse und Schlüssel eintragen → Verbinden.
  3. Zum Verwalten (Lektionen, Profile, Gruppen): oben rechts den Schalter Admin einschalten und das Admin-Passwort eingeben.

Laufende Nutzung

Im Alltag

  • Nichts zu tun. Der Pi einfach eingeschaltet lassen – er braucht kaum Strom. Er startet nach einem Stromausfall von selbst wieder (dauert etwa eine halbe Minute).
  • Ist der Pi nicht erreichbar, arbeiten die Geräte lokal weiter und gleichen später automatisch ab. Es geht nichts verloren.
  • Zum Ausschalten besser vorher herunterfahren: sudo shutdown now (danach Strom trennen).

Verbindungsdaten und Passwort ansehen oder ändern

Per SSH am Pi anmelden (Schritt 2) und dann:

# Adresse, Links, Schlüssel, Passwort und QR-Code anzeigen
cd /opt/tipptrainer && sudo -u tipptrainer ./tipptrainer-server --info

# nur das Admin-Passwort anzeigen
sudo -u tipptrainer ./tipptrainer-server --passwort

# Admin-Passwort ändern (gilt sofort, mindestens 4 Zeichen)
sudo -u tipptrainer ./tipptrainer-server --passwort-setzen NEUESPASSWORT

Die Befehle müssen im Ordner /opt/tipptrainer ausgeführt werden. Das Admin-Passwort lässt sich bewusst nicht in der App ändern, damit alle Geräte dasselbe Passwort haben.

Sicherung (Backup)

  • Alle Daten liegen im Ordner /opt/tipptrainer/TippTrainer-Daten: daten.json (aktueller Stand), Sicherungen/ (die letzten 50 Fassungen) und einstellungen.json (Schlüssel, Passwort).
  • Diesen Ordner regelmäßig auf den eigenen Rechner kopieren. Der Ordner gehört dem Dienst, deshalb zuerst auf dem Pi (per SSH) ein Archiv anlegen: 
    sudo tar -czf ~/TippTrainer-Sicherung.tar.gz -C /opt/tipptrainer TippTrainer-Daten && sudo chown $USER ~/TippTrainer-Sicherung.tar.gz
    und es dann auf dem eigenen Rechner abholen: 
    scp BENUTZER@tipptrainer.local:TippTrainer-Sicherung.tar.gz .
  • Zusätzlich gibt es in der App das Gesamt-Backup (Gruppenübersicht, im Admin-Modus).

Programm aktualisieren

Neue Fassung wie in Schritt 3 laden und entpacken, dann erneut sudo sh installieren.sh ausführen. Alle Daten, Schlüssel und das Passwort bleiben erhalten. Die Geräte müssen nichts tun.

Dienst steuern und Fehler suchen

sudo systemctl status tipptrainer      # läuft er?
sudo systemctl restart tipptrainer     # neu starten
sudo journalctl -u tipptrainer -n 30   # letzte Meldungen
sudo reboot                            # Pi neu starten

Entfernen

cd TippTrainer-Server
sudo sh deinstallieren.sh              # Dienst und Programm entfernen, Daten bleiben
sudo sh deinstallieren.sh --mit-daten  # auch die Daten löschen

Der Pi kommt in ein anderes Netz

Schlüssel und Passwort bleiben gleich – sie liegen auf dem Pi, nicht im Netz. Nur die IP-Adresse ändert sich.

  1. Am besten per Netzwerkkabel anschließen. Dann braucht der Pi keine Einrichtung.
  2. Neues WLAN: Pi erst per Kabel (oder mit Monitor und Tastatur) erreichbar machen, dann:
    sudo nmcli device wifi connect "NETZNAME" password "WLAN-PASSWORT"
    (Alternativ sudo nmtui für ein Menü.)
  3. Pi finden: tipptrainer.local funktioniert meist auch im neuen Netz. Sonst die IP in der Geräteliste des Routers suchen.
  4. Geräte, die mit dem Namens-Link eingerichtet wurden, finden den Pi von selbst. Wurde mit einer IP-Adresse eingerichtet, tragen Sie die neue Adresse in der App ein (Speicher-Symbol → Eigener Server) oder verbinden das Gerät erneut über den Link aus --info.

Wenn etwas nicht klappt

ProblemLösung
„Server nicht erreichbar“ in der AppSind Gerät und Pi im selben Netz? (Viele Schul-WLANs trennen Geräte untereinander – Rückfrage bei der Schul-IT.) Läuft der Dienst (sudo systemctl status tipptrainer)? Probeweise die IP-Adresse statt des Namens eintragen: Klappt das, löst das Gerät den Namen ….local nicht auf, oder der Router kennt noch eine veraltete Adresse für den Pi (alten Eintrag im Router löschen, dem Pi eine feste IP geben).
Die App wurde geöffnet, aber „Verbinden“ scheitertDie App muss vom Pi geöffnet werden (http://tipptrainer.local:8080). Von einer https-Seite (z. B. der Online-Fassung auf GitHub Pages) blockiert der Browser die Verbindung zum Pi. Am Mac: Systemeinstellungen → Datenschutz & Sicherheit → Lokales Netzwerk muss für den Browser erlaubt sein.
ssh findet tipptrainer.local nichtPi und Rechner im selben Netz? Etwas warten (nach dem Einschalten dauert es ca. 1–2 Minuten). Sonst IP aus der Router-Geräteliste verwenden.
Es ging gestern, heute nichtStrom und Netzwerkkabel prüfen. Per SSH --info aufrufen: Hat der Pi eine neue Adresse bekommen? (Dauerhaft vermeiden: im Router eine feste IP für den Pi reservieren.)
Port 8080 ist belegt (läuft noch ein anderes Programm)Der Server weicht automatisch auf den nächsten freien Port aus (8081 …). Dann ändert sich die Adresse für die Geräte. Besser: in /opt/tipptrainer/TippTrainer-Daten/einstellungen.json den Wert "port" auf eine freie Nummer (z. B. 8090) setzen und sudo systemctl restart tipptrainer ausführen.
Passwort vergessenPer SSH am Pi: sudo -u tipptrainer ./tipptrainer-server --passwort (im Ordner /opt/tipptrainer).
Alte Fassung wiederherstellensudo systemctl stop tipptrainer, gewünschte Datei aus Sicherungen/ als daten.json kopieren (Besitzer tipptrainer beibehalten), sudo systemctl start tipptrainer.

Datenschutz und Sicherheit – kurz

  • Es ist kein Cloud-Anbieter beteiligt. Die Daten (Gruppen, Profilnamen, Lektionen, Lernstände) bleiben im Schulnetz auf dem Pi.
  • Die Übertragung im Schulnetz erfolgt über http (unverschlüsselt). Der Pi sollte deshalb nicht direkt aus dem Internet erreichbar sein – keine Portfreigabe im Router einrichten.
  • Wer den Schlüssel kennt, kann die Daten lesen und ändern. QR-Code und Schlüssel nur an Lehrkräfte und die eigenen Geräte weitergeben.
  • Das Admin-Passwort schützt die Verwaltung in der App vor neugierigen Kindern; es ist kein Hochsicherheits-Schutz.
  • Den Einsatz mit der bzw. dem Datenschutzbeauftragten der Schule abstimmen.
